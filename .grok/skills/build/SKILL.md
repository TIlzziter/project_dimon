# Реализация

1. Прочитай `docs/features/<имя>/spec.md` и `dev-state.json`. Нет спеки и задача шире одного файла — сначала `/spec`.
2. Пиши код сам. Субагент-реализатор не нужен. `explore` — только если не находишь место правки.
3. Не расширяй объём за разделом «что не входит».
4. Выполни команду из `.grok/check-command.txt`, если она задана. Падение тестов чини до отчёта о готовности.
5. Обнови `dev-state.json`: `status: "built"`, что изменилось, что осталось.
6. Если в ходе работы выяснилось поведение, которого нет в спеке, допиши его в спеку в том же ходе.
7. Коммит не делай.

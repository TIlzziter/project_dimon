# Ревью

1. Запусти субагента с ролью `reviewer` (она встроена в Grok Build). В задании укажи путь заметок `docs/features/<имя>/review.md` и границу диффа. Своё ревью поверх не дублируй, пока заметки не прочитаны.
2. В ответ себе возьми только вердикт и список замечаний с путями. Полный текст лежит в файле.
3. Замечания поправь сам следующим ходом, если пользователь не просил только отчёт. После правок снова выполни команду проверки, если она задана.
4. В `dev-state.json` поставь `status: "reviewed"` и одну строку вердикта.
